## Repository Introduction



[Qdrant](https://github.com/qdrant/qdrant)  is an open-source vector database optimized for high-performance vector retrieval and similarity search.This product provides an out-of-the-box qdrant based on the Huawei Cloud EulerOS 2.0 64-bit system of Kunpeng servers.

## Core Features

- **Dynamic data management:** Supports real-time data updates and deletions, enabling hot updates to data without the need to rebuild indexes
- **High-performance vector search:**Adopting an efficient HNSW (Hierarchical Navigable Small World) index structure, it supports rapid retrieval of large-scale vector data and boasts millisecond-level response capabilities

The open-source image product [**Qdrant vector database**](https://marketplace.huaweicloud.com/hidden/contents/a2924718-220e-4362-93f9-e390fcb577af#productid=OFFI1132209787291230208) provided by this project has pre-installed the 1.14.0 version of qdrant and its related runtime environment, and provides deployment templates. Come and refer to the usage guide to easily start an efficient "out-of-the-box" experience!

> **System requirements are as follows:**
>
> - CPU: 2 vCPUs or higher
> - RAM: 4GB or larger
> - Disk: At least 40GB
